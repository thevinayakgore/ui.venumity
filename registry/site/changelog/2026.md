## Project Launch & CLI Introduction 🚀

The very first commit marks the official start of the **Venumity UI** project. This initial milestone establishes the core structure, development environment, and the project's guiding philosophy: building beautiful, accessible, and production-ready React components for everyone to copy, paste, and ship.

A key part of this launch is the introduction of the **Venumity CLI**, an intelligent command-line tool that allows you to quickly scaffold components, initialize projects, and manage your setup with automatic framework and package manager detection.

**Highlights**
- Initial project scaffolding with Next.js, Tailwind CSS, and Framer Motion.
- First npm package publication (`venumity@1.0.31`).
- CLI support for `npx venumity add` commands.
- Auto-detection for project framework (Next.js/Vite) and language (TypeScript/JavaScript).

## Pricing Table Components 💰

This update introduces **Pricing Table** components, allowing developers to create beautiful and flexible pricing sections for their SaaS products or any subscription-based service. The components are fully customizable, support multiple tiers, and come with ready-to-use animations.

**What's new ?**
- Three pricing tier variants (Basic, Pro, Enterprise).
- Toggle between monthly and annual billing.
- Feature list with checkmarks and tooltips.
- Smooth hover effects and transitions.
- Fully responsive design for all screen sizes.

**Example usage**
```tsx
import { PricingTable } from "@venumity/ui";

<PricingTable
  tier="Pro"
  price="$29"
  features={["Unlimited projects", "Priority support", "Advanced analytics"]}
/>
```

## New Navbar & Background-Effect Component ✨

The final featured update of this period introduces two highly requested components: a **modern, responsive navbar** and a **background-effect component** (such as animated gradients or particle backgrounds). These additions elevate the visual appeal of any project while maintaining performance and accessibility.

**Navbar Features**
- Sticky positioning with smooth scroll behavior.
- Mobile hamburger menu with slide-out animation.
- Support for dropdowns, mega-menus, and search bars.
- Fully customizable via Tailwind CSS classes.

**Background-Effect Component Features**
- Animated gradient blobs (Aurora-like effect).
- Particle network or confetti backgrounds.
- Mouse-tracking glow effects.
- Optimized with `will-change` and `transform` for 60fps animations.

**Get started**
```bash
npx venumity add navbar-animated
npx venumity add background-aurora
```
