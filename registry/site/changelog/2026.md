## 🚀 Venumity UI CLI v1.0.0

We're thrilled to announce the official release of **Venumity UI CLI v1.0.0** - the fastest way to add production-ready components to your Next.js project.

#### ✨ What's New

- **One-command installation** — Install components directly with `npx venumityui@latest add <component-name>`
- **122+ components** — Access the entire component library from your terminal
- **Auto-dependency detection** — The CLI automatically detects and installs required npm & shadcn/ui dependencies
- **Folder-based component support** — Multi-file components like `personal-panel-1` are fully supported
- **Zero configuration** — Just run and go

#### 📦 Available Commands

| Command                                        | Description                      |
| ---------------------------------------------- | -------------------------------- |
| `npx venumityui@latest add <component>`        | Add one or more components       |
| `npx venumityui@latest add --all`              | Install all available components |
| `npx venumityui@latest list`                   | List all components              |
| `npx venumityui@latest search <query>`         | Search components                |
| `npx venumityui@latest info <component>`       | View component details           |
| `npx venumityui@latest categories`             | List all categories              |
| `npx venumityui@latest subcategory <category>` | List subcategories               |

#### 💻 Quick Start

```bash
# Add a single component
npx venumityui@latest add profile-card-1

# Add a folder-based component
npx venumityui@latest add personal-panel-1

# Add multiple components
npx venumityui@latest add profile-card-1 basic-accordion ai-chat-bot-1
```

**Links -** [CLI Documentation](https://www.npmjs.com/package/venumityui) · [Components](https://ui.venumity.com/components)

## 🚀 Venumity UI - Initial Launch

We are thrilled to announce the official launch of **Venumity UI** — a modern React component library designed to help developers build beautiful, production-ready web applications faster than ever before.

#### 🎯 The Vision

Venumity UI was born from a simple idea: **developers deserve beautiful, functional components that work out of the box.** No bloated dependencies, no complex configuration — just clean, minimal code that you can drop into your Next.js projects and start building immediately.

#### ✨ What We Launched With

| Feature                  | Description                                                |
| ------------------------ | ---------------------------------------------------------- |
| **🎨 20+ Components**    | Cards, Navigation, Forms, and more                         |
| **⚡ Next.js Optimized** | Built specifically for Next.js 14+ with App Router support |
| **🎭 Dark/Light Mode**   | Full theming support with Tailwind CSS                     |
| **📱 Responsive**        | Every component looks great on all devices                 |
| **🧩 TypeScript**        | Fully typed for better developer experience                |
| **🎨 Customizable**      | Easy to style with Tailwind classes                        |

#### 🛠️ Technology Stack

- **Framework -** Next.js 14 (App Router)
- **Styling -** Tailwind CSS
- **Language -** TypeScript
- **UI Library -** shadcn/ui components
- **Animations -** Framer Motion
- **Icons -** Lucide React
