# Welcome to Venu<span style="color:orange">mity</span> UI 🎉

**Venu<span style="color:orange">mity</span> UI** is a collection of modern, customizable UI components built with React and Tailwind CSS. Whether you're building a startup MVP, a side project, or a production application, our components help you ship faster with beautiful, accessible interfaces.

---

### What's Included

- **Free Components** : 50+ MIT-licensed components ready to use
- **Premium Templates** : Complete layouts and design systems ($0-$40)
- **Zero Dependencies** : Minimal footprint, maximum flexibility
- **TypeScript Ready** : Full type definitions included
- **Responsive Design** : Works on all screen sizes

---

### Quick Start Options

- **Copy & Paste** : Browse components → Copy code → Use in your project
- **CLI Tool** : Coming soon - install components via command line
- **Manual Setup** : Clone individual components from GitHub

---

### Your First Component

Here's how easy it is to use a **Venu<span style="color:orange">mity</span> UI** component :

```tsx
// 1. Copy component code from our website
// 2. Paste into your project
// 3. Start customizing

import { Button } from "@/components/ui/button";

function App() {
  return <Button variant="primary">Click Me</Button>;
}
```
